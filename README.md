# The Drift Index — Vercel Deployment

## What this is
The Drift Index is a human performance diagnostic by Inspired Intentions.
Built by Hayley Standen © 2026.

## How to deploy to Vercel (5 minutes, no coding needed)

### Step 1: Create a free Vercel account
Go to vercel.com and sign up with your email or GitHub account.

### Step 2: Upload this folder
- In Vercel, click "Add New Project"
- Choose "Upload" (you don't need GitHub for this)
- Drag and drop this entire folder

### Step 3: Deploy settings
Vercel will auto-detect this as a Vite project. Leave all settings as default.
Click "Deploy."

### Step 4: Get your link
In under 2 minutes Vercel will give you a live URL like:
`https://drift-index.vercel.app`

You can share this link immediately.

### Optional: Add your own domain
If you register thedriftindex.com or thedriftindex.co.uk, you can connect it
to Vercel in Settings > Domains. Vercel will walk you through it step by step.
